## Page 22：我的（首页）

### 页面定位

个人中心首页，汇总用户的核心信息、数据资产和功能入口。

### 核心信息架构

- 用户头部：头像、昵称、城市、一句话状态（可选）
- 核心数据卡片：记录天数、完成目标数、参加活动数、探索地点数（本周/本月）
- 会员状态条（非会员时显示升级引导）
- 功能入口列表：
  - 我的收藏
  - 我的活动
  - 我的回忆（Life Story入口）
  - 通知
  - 个人资料
  - 会员中心
  - 设置
- 底部：版本号

### 状态清单

#### 1. 已登录

- 头像、昵称、城市、一句话状态。
- 本周/本月核心数据预览（记录天数、完成目标数、参加活动数）。
- 会员状态标识。

#### 2. 未登录/登录过期

- 引导登录。
- **游客模式下展示可用功能预览**，不强制登录。
- 说明哪些功能需要登录（保存数据、参与活动等）。

#### 3. 数据同步中

- 展示同步状态（小loading/提示"正在同步"）。
- 防止用户担心数据丢失。

### 交互细节

- 数据预览卡片可点击进入对应模块（Mood/Growth/Community/Explore）。
- 编辑资料入口明显（头像旁边或资料卡片上）。
- Life Story入口作为特色功能突出展示（不是普通列表项，可以用卡片形式）。

### 极端情况

| 场景 | 处理方式 |
| --- | --- |
| 账户异常（被冻结/需验证） | 清晰说明和解决路径 |
| 多设备登录冲突 | 提醒并提供设备管理入口 |
| 新用户（数据全为零） | 不显示零数据，改为"开始记录你的第一天"引导 |

## Page 23：个人资料编辑

### 页面定位

编辑个人基础信息和偏好，这些偏好**直接影响AI推荐质量**。

### 核心信息架构

- 头像编辑（拍照/相册）
- 昵称
- 城市
- 一句话介绍（可选）
- 兴趣标签（多选，影响Explore推荐）
- 日常预算（滑块，影响活动推荐价位）
- 生活方式标签（安静/活跃/户外/室内/早起/夜猫子等）
- 隐私设置入口

### 状态清单

#### 1. 正常编辑

- 头像、昵称、城市、一句话介绍。
- 兴趣标签多选（影响Explore推荐）。
- 日常预算设置。
- 生活方式标签。

#### 2. 未设置偏好

- 提示"完善偏好后，AI会更懂你"。
- 但非强制，用户可以跳过。

#### 3. 隐私设置

- 谁可以看到我的活动（公开/仅活动参与者/仅自己），默认仅活动参与者。
- 位置数据使用偏好。

### 交互细节

- 兴趣标签选择器流畅，支持搜索和热门标签推荐。
- 预算设置滑块形式，直观易用。
- 所有修改**实时保存**，无需额外确认按钮。
- 生活方式标签影响Today首页的AI推荐语气和内容。

### 极端情况

| 场景 | 处理方式 |
| --- | --- |
| 预算设为零 | 提供"免费活动"偏好开关，不让推荐算法崩溃 |
| 选择"不暴露任何信息" | 尊重选择，AI推荐相对泛化，Today首页提示差异让用户权衡 |
| 用户换城市 | 清空基于位置的缓存数据，重新学习偏好；提示"换了城市？我会重新了解这里" |

## Page 24：会员中心

### 页面定位

展示会员权益、订阅状态和付费入口。

### 核心信息架构

- 会员状态头部（会员徽章+到期时间/升级引导）
- 权益对比表（免费 vs 会员）
- 订阅方案选择（月/季/年）
- 续费/升级按钮
- 管理订阅入口
- 会员专属功能预览

### 状态清单

#### 1. 免费用户

- 会员权益对比表（当前 vs 会员）。
- 引导升级。
- 权益包括：AI高级规划、旅行规划、人生总结、年度报告、AI教练、高级数据分析。

#### 2. 付费会员

- 会员身份标识。
- 到期时间。
- 权益使用情况。
- 续费入口。

#### 3. 会员到期

- 提醒续费，但不过度骚扰。
- 降级后的数据保留说明（收藏/回忆等数据不丢失）。

#### 4. 无商业化阶段

- 可以先作为"成就墙"或"徽章展示"。
- 后期平滑过渡到付费会员。

### 交互细节

- 升级页面需要清晰的CTA和价值主张。
- 管理订阅入口（跳转App Store/Google Play管理说明）。
- 权益展示要具体，不用模糊的"更多AI"描述。

### 极端情况

| 场景 | 处理方式 |
| --- | --- |
| 支付失败/订阅异常 | 明确恢复购买和客服入口 |
| 用户想退款 | 清晰路径，避免负面评价 |
| 用户质疑会员价值 | 提供试用/免费体验部分功能 |

### 产品逻辑断裂点（待修复）

- [ ] 页面未创建
- [ ] 权益对比设计
- [ ] 订阅方案选择

## Page 25：通知中心

### 页面定位

汇总系统通知、AI提醒、活动更新、互动消息。

### 核心信息架构

- 分类tab：全部 / AI / 活动 / 系统
- 通知列表（已读/未读区分）
- 通知偏好设置入口

### 状态清单

#### 1. 有未读通知

- Tab上红点。
- 按时间排序。
- 已读未读视觉区分（背景色/字重）。

#### 2. 无通知

- 空状态："暂无新消息 🎉"
- 不显示"暂无数据"这种冰冷文案。

#### 3. 通知分类

- **AI消息**：今日规划生成、情绪洞察、建议提醒
- **活动通知**：报名确认、活动变更、聊天室消息
- **系统通知**：更新、提醒、账户相关

### 交互细节

- 单条滑动删除。
- 批量标记已读。
- 每条通知点击跳转到对应具体页面（活动详情/今日规划等），**不能只是看通知**。
- 通知偏好设置入口（跳转设置页通知部分）。

### 极端情况

| 场景 | 处理方式 |
| --- | --- |
| 通知过多骚扰用户 | 细颗粒度通知开关（每个类别单独设置），默认低频模式 |
| 敏感内容通知 | 锁屏通知不显示地点详情或情绪内容，做隐私处理 |
| 通知过期（活动已结束） | 自动标记已读或归档，不堆积 |

## Page 26：设置

### 页面定位

应用全局设置、隐私、偏好管理。

### 核心信息架构

- 常规设置
  - 主题（跟随系统/浅色/深色）
  - 语言
  - 字体大小（无障碍）
- 通知设置
  - 细颗粒度开关：AI规划/活动/互动/系统
- 隐私设置
  - 位置权限管理
  - 数据收集说明
  - 个性化推荐开关
  - 清空数据
  - 导出数据
  - 注销账户
- AI偏好
  - 饮食偏好
  - 交通方式
  - 活动强度
  - 预算范围
  - 是否接受拼团/多人活动
- 关于
  - 版本号
  - 用户协议
  - 隐私政策
  - 反馈入口
  - 评分引导

### 状态清单

各设置项正常工作状态。重点关注隐私相关操作的安全确认。

### 交互细节

- 每个设置项清晰明了的开关或导航。
- 隐私操作（清空数据、注销）必须有二次确认+冷静期设计。
- 反馈入口：简单表单或内置轻反馈渠道。
- AI偏好设置直接影响推荐，修改后有轻量提示"已更新，下次推荐会有所不同"。

### 极端情况（合规底线）

| 场景 | 处理方式 |
| --- | --- |
| 用户注销账户 | 彻底删除或按法规匿名化数据；流程中明确告知哪些删除、哪些保留多久 |
| 儿童用户 | 如有年龄验证，符合儿童隐私保护法规 |
| 数据导出请求 | 提供通用格式导出（JSON/CSV），响应时间符合法规要求 |
| 用户关闭个性化推荐 | 明确告知推荐质量会下降，但完全尊重用户选择 |

## 设计原则（全局）

1. **简洁不杂乱**：个人中心不做信息流，不做推荐，就是工具入口。
2. **数据透明**：用户清楚自己的数据被如何使用，隐私设置不藏深。
3. **可控性**：通知、隐私、AI偏好都有明确开关，用户有完全控制权。
4. **实时保存**：设置修改即时生效，不需要"保存"按钮。
5. **不强制登录**：游客模式可用核心功能，登录引导不打断。
6. **合规底线**：数据删除、导出、注销符合隐私法规，这是产品生存底线。
