# Explore 模块产品评审文档

> 模块定位：以地图为主要交互界面，展示可探索的地点、路线和活动。
> 核心理念：不是地图导航工具，而是"今天适合去哪里"的AI策展。
> 与 Today 的关系：Today 告诉你今天做什么，Explore 告诉你去哪做。

## Page 06：地图（Explore 首页）

### 页面定位

Explore Tab 的默认着陆页，以地图为主要交互界面，展示可探索的地点、路线和活动。

### 核心信息架构

- 顶部：搜索栏 + 筛选入口
- 地图主区域：地点图标（不同颜色区分类型）
- 底部：可上滑的推荐列表/路线推荐
- 分类切换条（咖啡/书店/公园/展览/运动/City Walk/电影/夜骑）

### 状态清单

#### 1. 首次打开 / 无偏好

- 不能是空白地图。
- 默认展示当前区域高评分、符合当下时间的热门地点（咖啡馆、书店、公园）。
- 不同颜色图标区分类型。
- 提供轻量的"今天想找什么？"快捷切换条。

#### 2. 用户已设置偏好

- 地图图标根据偏好自动调整显示优先级。
- 例：用户偏好安静、独自活动 → 茶馆、图书馆优先于酒吧。

#### 3. 无位置权限

- 回退到手动选城市场景。
- 地图中心默认城市热门区域。
- 提供"开启位置以发现附近"引导条，不强制打断。

#### 4. 网络异常

- 使用缓存的地图瓦片和上次加载的地点数据。
- 顶部提示"当前展示的是离线数据，可能已过时"。

### 交互细节

- **单点地点图标** → 弹出轻量预览卡片（名称、标签、评分、距离），不跳转页面，减少层级。点击卡片进入详情。
- 地图底部保留可滑动横向列表，展示"推荐路线"（今日City Walk等），点击跳转 Route 规划页。
- 双指缩放时动态聚类，避免密集区图标重叠。
- **夜间模式暗色地图**很重要（晚间使用场景多）。

### 极端情况

| 场景 | 处理方式 |
| --- | --- |
| 快速拖动/缩放加载大量数据 | 防抖处理 + 地点加载骨架屏，避免图标闪烁 |
| 城市边缘/郊区数据稀疏 | 主动扩大搜索半径，提示"已扩展至5km范围"；展示最近城镇中心 |
| 国外/异地 | 考虑多语言地点名；推荐逻辑适应当地特色（居酒屋而非烧烤） |
| 深夜（23:00后） | 地图自动切换夜间模式，推荐24h场所/便利店 |

### 产品逻辑断裂点（待修复）

- [ ] 当前原型只有卡片流，没有地图视图
- [ ] 缺少地点图标预览卡片（点击不直接跳转）
- [ ] 缺少夜间暗色地图模式
- [ ] 缺少位置权限拒绝态
- [ ] 缺少离线/弱网缓存展示
- [ ] 缺少缩放聚类逻辑

## Page 07：地点详情

### 页面定位

展示单个地点的完整信息，帮助用户决策是否前往。

### 与 Today 活动详情的关系

- Today Page 04：侧重"为什么**此时**推荐给你"
- Explore Page 07：侧重"客观信息 + 为什么**适合你**"
- 共用大部分UI组件（Hero/信息卡/评价），但推荐理由文案逻辑不同
- 收藏状态**双向同步**

### 状态清单

#### 1. 正常详情

- 图片轮播（或渐变氛围图）
- 地点名称、类型标签
- 营业时间、地址、电话
- AI推荐理由（"适合一个人安静阅读"）
- 用户评价（简版）
- 距离和交通建议

#### 2. 该地点正在举办临时活动

- 如"今晚有爵士乐演出"。
- 顶部醒目但不打断显示，标注剩余时间。

#### 3. 已收藏状态

- 心形图标实心。
- 提供"查看收藏夹"快捷入口（跳转 Page 09）。

#### 4. 地点已关店/暂停营业

- 标记"暂停营业"并显示最后确认时间。
- 提供"报错"入口（群众修正）。

#### 5. 无网络时查看缓存

- 若之前加载过，展示缓存数据并提示离线。

### 交互细节

- **一键导航**：调起系统地图 App，带名称和坐标。
- **分享地点卡片**：生成美观卡片，支持微信/朋友圈。
- **"添加到我的一天"**：一键将此地添加到 Today 的时间块中，自动根据当前时间建议放在上午/下午/晚上。**这是促活关键，连接两个模块。**
- 评价系统：快捷感受选择（"安静""氛围好""难找"），不强求长篇评价。同时可对"推荐准确性"打分，给AI反馈。
- **历史打卡提示**："你上次来这里是在 2026年3月"（情感钩子，防止重复推荐厌倦地点）。

### 极端情况

| 场景 | 处理方式 |
| --- | --- |
| 信息不完整（缺营业时间） | 标注"暂无时间信息，建议电话确认"，不隐藏字段 |
| 危险/敏感地点 | 悬崖/废弃工厂等无安全保障的不收录；若收录需安全警告 |
| 连锁/多分店 | 明确当前是哪个分店，提供切换入口 |
| 价格超预算 | 显示实际价格，标注"超出你今天的预算 ¥XX"，但不禁止选择 |

### 产品逻辑断裂点（待修复）

- [ ] 与 Today 活动详情的区分（推荐理由文案逻辑不同）
- [ ] "添加到我的一天"按钮（连接Today模块）
- [ ] 快捷感受标签评价
- [ ] 历史打卡提示
- [ ] 临时活动横幅
- [ ] 关店/暂停营业状态

## Page 08：路线规划（Route）

### 页面定位

展示一条完整的活动路线（如City Walk），包括途经点、预计时间、导航和AI推荐拍照点。

### 核心信息架构

- 顶部：返回 + 路线名称 + 收藏/分享
- 路线概览卡：总距离、预计耗时、难度、适宜时段
- 地图路线预览（静态或简化路线图）
- 途经地点列表（时间轴形式）
- 拍照点标记（相机图标）
- 底部："开始行走"主按钮

### 状态清单

#### 1. 预设路线

- 总距离、预计耗时、途经地点列表（可展开详情）。
- 地图路线预览。
- 可切换交通方式（步行/骑行/公交）。

#### 2. 动态路线（行走中）

- 若路线中某个地点临时关闭或用户跳过，提供"跳过此点"并自动调整剩余路径，重新计算时间。
- 实时显示当前位置，已走距离，下个转向提示。
- 可上滑查看后续点。

#### 3. 无数据/生成失败

- 提示"当前区域暂时没有合适的路线，试试探索附近地点自己组合？"
- 永远提供保底出路。

### 交互细节

- 沿路添加新地点（搜索沿途咖啡馆），拖拽调整顺序。
- **拍照点提示**：路线地图上用相机图标标记，点击可预览示例照片角度，增强趣味性。
- **分享路线**：生成长图，包含路线概览、预计时长和亮点。社交传播素材。
- "开始行走"按钮：点击进入导航模式，记录行走数据（同步到Growth模块）。

### 极端情况

| 场景 | 处理方式 |
| --- | --- |
| 路线太长（>15km） | 提示建议骑行或分两天 |
| 路线中有难走路段（山路/无路灯） | 警告并建议白天或结伴 |
| GPS信号弱（隧道/室内） | 平滑处理，不乱跳；丢失信号时提示"正在重新定位" |
| 天气突变（行走中下雨） | 推送附近避雨地点，询问是否调整路线 |

## Page 09：收藏夹

### 页面定位

集中管理用户收藏的地点、路线、活动和电影。与Today活动详情、Explore地点详情的收藏是**同一个数据池**。

### 核心信息架构

- 顶部：返回 + "我的收藏"
- 分类tab：全部 / 地点 / 路线 / 活动 / 电影
- 收藏列表/网格
- 空收藏引导

### 状态清单

#### 1. 空收藏

- 温和引导："还没有收藏？在地图上点击小心心，把喜欢的地方留下来。"
- 提供1-2个根据偏好自动生成的示例收藏夹（如"杭州必去书店"），让用户有初始内容可逛。

#### 2. 正常收藏

- 分类展示（地点、路线、电影等）。
- 支持列表和网格视图切换。
- 每个卡片包含封面、标题、标签、收藏时间。

#### 3. 收藏项失效

- 地点关店/活动取消：标记灰色，提示"已失效"，提供移除或查看替代推荐。

#### 4. 自定义收藏夹

- 支持创建自定义收藏夹（"周末去处""约会备选"）。

### 交互细节

- 支持自定义收藏夹创建和管理。
- 从收藏直接添加到 Today 或 Route。
- 批量编辑模式：多选移除或移动到其他收藏夹。
- 搜索和排序（按距离、收藏时间、最近去过）。

### 极端情况

| 场景 | 处理方式 |
| --- | --- |
| 收藏数百个地点 | 提供搜索+排序+筛选，否则变成死列表 |
| 收藏的地点数据源失效 | 灰色标记+替代推荐 |
| 跨设备同步（未来） | 需要考虑数据一致性和冲突解决 |
