# Solo - AI 生活操作系统 产品架构文档

> 产品名称：Solo（暂定名 Today / ONE）
> 定位：AI 生活决策平台，不是社交 App，不是工具 App，不是 AI 聊天 App
> Slogan：今天，过得值得一点。
> 核心理念：今天出去生活吧。AI 负责规划、推荐、提醒、陪伴，而不是让你继续待在手机里。

---

## 一、产品哲学

很多 App 在抢时间：抖音让你刷2小时，微博让你刷新闻，小红书让你刷攻略，微信让你聊天。

**Solo 只有一句话：今天出去生活吧。**

- AI 负责规划、推荐、提醒、陪伴。
- 不是让你继续待在手机里。
- 每天打开一次，它帮你决定今天值得做什么。
- 竞争对手不是微信、抖音、小红书，而是用户每天面对的问题："今天下班以后，我到底该干什么？"

---

## 二、商业模式

```
AI → 推荐 → 消费 → 平台抽佣
```

推荐覆盖：咖啡店、餐厅、展览、演出、课程、旅行、酒店、电影院、健身、City Walk。

会员体系：
- AI 高级规划
- 旅行规划
- 人生总结
- 年度报告
- AI 教练

## 四、核心用户流程（User Flow）

### 4.1 每日主流程（最核心）

```
打开App
  ↓
Today 首页（3秒看到今天怎么过）
  ↓
┌─ 满意 → 点击某个活动 → 活动详情 → 导航/标记 → 出门
│
├─ 想看完整个安排 → 今日规划详情 → 点击活动 → 活动详情
│
├─ 计划被打乱（下雨/不想出门/预算变了）
│   ↓
│  AI 重新规划 → 选择场景/调整参数 → AI生成中（等待态）
│   ↓
│  新规划对比 → 采用/部分替换 → 回到首页
│
└─ 晚上回来
    ↓
  今日总结 → 回顾完成项 → 记录心情 → AI寄语 → 晚安
    ↓
  （可选）分享今日卡片到社交平台
```

### 4.2 探索流程

```
Today/Explore Tab
  ↓
看到推荐 → 地点详情（AI推荐理由）
  ↓
导航前往 / 收藏 / 加入今日计划
  ↓
（可选）地图模式 → 筛选分类 → 选点 → 路线规划
```

### 4.3 同行（临时社交）流程

```
Community Tab / Today 附近推荐
  ↓
看到活动卡片 → 活动详情（几缺几/时间/地点）
  ↓
加入活动 → 临时聊天室（活动期间存在）
  ↓
活动结束 → 聊天室自动关闭 → 可互相评价但无好友关系
```

### 4.4 情绪记录流程

```
Mood Tab / 今日总结中的心情入口
  ↓
一键选择表情（🙂😐😔😭）
  ↓
（可选）AI 分析建议 → 推荐活动/休息
  ↓
日历/趋势查看历史（不强制）
```

## 五、AI Agent 架构（2.0+ 演进方向）

多 AI Agent 协作系统：

| Agent | 职责 |
| --- | --- |
| 生活规划 Agent | 安排一天/一周/一月的生活节奏 |
| 健康 Agent | 结合睡眠、运动、饮食给出建议 |
| 探索 Agent | 发现附近适合独处/参与活动的新地点 |
| 预算 Agent | 根据消费能力推荐不同价位体验 |
| 成长 Agent | 把阅读/学习/运动等长期目标拆解成每日小任务 |
| 社交 Agent | 仅在用户愿意时，推荐符合兴趣的临时同行活动 |

## 六、设计系统（Design Tokens）

### 6.1 色彩体系

- **主色**：温暖日出橙 `#F97316`
  - 代表阳光、温暖、新的一天、活力
  - 色阶：50(#FFF7ED) → 900(#7C2D12)
- **中性色**：暖石色系
  - 50(#FAFAF9) → 900(#1C1917)
  - 偏暖不偏冷，避免冷灰色的科技感
- **语义色**：
  - 成功：#22C55E
  - 警告：#F59E0B
  - 错误：#EF4444
  - 信息：#3B82F6

### 6.2 圆角体系

- `sm`: 8px（小标签、按钮）
- `md`: 12px（小卡片）
- `lg`: 16px（主要卡片、按钮）
- `full`: 9999px（胶囊按钮、头像、圆形进度）

### 6.3 字体

- 系统无衬线字体栈：SF Pro Display / PingFang SC / Hiragino Sans GB / Microsoft YaHei
- 标题：font-semibold
- 正文：font-normal
- 辅助文字：text-muted-foreground

### 6.4 间距

- 页面水平内边距：16px（手机）
- 卡片间距：16px（space-y-4）
- 卡片内边距：16px（p-4）
- 底部导航安全区：pb-20（80px）

## 七、全局交互模式

### 7.1 页面层级与导航

- **Tab 页面**（6个）：底部固定导航栏，6 列 grid
- **子页面/详情页**：顶部导航栏（返回 + 标题 + 操作），无底部 Tab
- **浮层/模态**：从底部滑出的 sheet 或居中卡片

### 7.2 卡片语言

- 白色背景 `bg-white`
- 细边框 `border border-border`（不使用重阴影）
- 圆角 `rounded-lg`（16px）
- 浮在图片上的卡片可以使用适度阴影
- 不允许彩色渐变作为普通卡片背景，渐变只用于：
  - 今日状态问候
  - Hero 区域
  - AI 寄语卡片
  - 特殊节日/深夜模式

### 7.3 图标

- UI 功能图标：Lucide Icons
- 内容情绪表达：Emoji（仅限内容中，不作为功能按钮图标）
- 图标尺寸：底部导航20px，列表项20px，小装饰16px

### 7.4 按钮

- 主按钮：`bg-primary text-white rounded-full`，padding: px-6 py-2.5/3
- 次按钮：`border border-primary text-primary rounded-full`
- 文字按钮：`text-primary` 无背景
- 危险操作：`bg-state-error text-white`

### 7.5 状态反馈

- 点击态：`active:opacity-70` 或 `active:scale-95`
- 收藏/喜欢：心形填充动效
- 完成：打勾动画 + 轻微颜色变化
- 加载：有温度的文案+动画（禁止使用单纯转圈）

## 八、情感设计原则

1. **温暖优先**：所有文案口语化，像朋友说话，不用机械的系统提示语。
2. **正反馈原则**：总结页永远不打击用户，零完成也"是重要的休息"。
3. **不施压原则**：成长页只激励不惩罚，"连续打卡"是成就不是压力。
4. **隐私安全感**：分享自动脱敏，位置数据模糊化，聊天室自动消失。
5. **AI 有性格**：不是冷冰冰的助手，是懂你的朋友。会说"今天辛苦了"。
6. **等待有温度**：所有加载态都配有趣的文案，等待时间不焦虑。
7. **不抢时间**：每次打开控制在 30 秒内能做出决定，然后放下手机去生活。

## 十一、全局产品原则汇总

从各模块评审中提炼的全局设计原则：

1. **零摩擦优先**：核心操作一键完成（记录心情、打卡、报名），不加步骤不加确认。
2. **温暖兜底**：空态、失败态、零完成态都要温暖，永远不说"无结果""你什么都没做"。
3. **信息折叠**：不摊开全部细节造成心理负担，给概览+展开入口。
4. **Agent 而非 Chatbot**：AI主动推荐、主动纠偏、主动兜底，不等用户问。
5. **只激励不惩罚**：成长不施压，情绪不诊断，未完成不是失败。
6. **事件型社交**：没有好友列表，没有朋友圈，活动结束聊天室自动删除。
7. **等待即体验**：加载态有温度，文案+动画 > 转圈。
8. **隐私底线**：分享自动脱敏，位置模糊化，数据可导出可删除，敏感年份温柔处理。
9. **离线可用**：核心路径（看规划、记心情、打卡）离线可用，不白屏。
10. **数据沉淀**：每次重新规划记录原因，每次推荐收集反馈，这是AI护城河。
