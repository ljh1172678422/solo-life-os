# Mood 模块产品评审文档

> 模块定位：最轻量的情绪数据采集入口，零摩擦记录，长期沉淀情绪洞察。
> 核心理念：不是心理咨询，而是生活建议的情绪信号源。
> 设计原则：自愿、轻量、温暖、不施压。

## Page 10：心情记录（Mood 首页）

### 页面定位

最轻量的一步式心情记录，是情绪数据的采集入口，**必须做到零摩擦**。

### 核心信息架构

- 顶部问候语（根据时间变化：早上好/下午好/晚上好）
- 核心交互：4个大表情按钮（😊 😐 😔 😭）居中
- 记录后的微动效反馈
- 可选标签区（记录后出现，非强制）
- 历史记录快捷入口

### 状态清单

#### 1. 正常记录（未记录今天）

- 四个表情醒目居中。
- 点击即完成记录，**无需确认按钮**。
- 记录后表情有微动效反馈（缩放+颜色变化），然后自动收起/切换到已记录态。

#### 2. 今日已记录

- 页面顶部显示今天选择的表情。
- 下方提供"今天心情有变化？"的轻量修改入口。
- 不鼓励频繁修改（修改入口样式克制）。

#### 3. 想要补充细节（可选）

- 记录表情后，出现可选标签选择（平静/焦虑/充实/孤独/感恩/疲惫/兴奋等）。
- 最多选3个，不是强制步骤。
- 标签区可以上滑关闭。

#### 4. 连续记录正向反馈

- 如果昨天记录了😔，今天记录了😊，轻量反馈："今天比昨天明亮了一些 ☀"。
- 不做夸张庆祝，保持温柔语气。

### 交互细节

- **长按某个表情**进入"带文字的记录"（高级操作，绝大多数用户只需点一下）。
- **不应有强迫性红点或推送**"今天你还没记录"，情绪记录是自愿的。
- 如果用户从今日总结（Page 05）触发心情记录入口，完成后应**回到总结页**，不打断原有流程。
- 记录完成后，可以轻量引导"看看最近的情绪变化"（跳转趋势页），但不是强制弹窗。

### 极端情况

| 场景 | 处理方式 |
| --- | --- |
| 一天内多次修改心情 | 保留最终记录；趋势数据中标记"波动日"作为特殊状态 |
| 连续多天记录😭 | **谨慎处理**：不做机械"振作起来"推送；AI分析中轻触"这段时间似乎很不容易"，提供专业求助热线入口（产品责任） |
| 用户误触 | 提供"撤销"toast（3秒内），不弹确认框 |
| 用户从未记录 | 不施压，每次打开Mood Tab都以友好问候开始 |

### 产品逻辑断裂点（待修复）

- [ ] 当前原型的4个表情按钮需加大、居中、突出零摩擦感
- [ ] 缺少记录后的微动效反馈
- [ ] 缺少可选标签区
- [ ] 缺少连续记录的正向轻反馈
- [ ] 缺少从今日总结入口的返回逻辑
- [ ] 连续低落状态的安全协议（求助资源入口）

## Page 11：心情日历

### 页面定位

月视图日历，用颜色直观展示一个月的心情变化，一眼即可感知。

### 核心信息架构

- 顶部导航：返回 + 月份切换
- 月历网格（7列x5行）
- 每天用颜色圆点/底色标记情绪
- 底部月度小统计

### 状态清单

#### 1. 当月数据完整

- 每天对应颜色标记：
  - 😊 → 暖橙色/绿色（开心）
  - 😐 → 黄色（平静）
  - 😔 → 蓝色（低落）
  - 😭 → 深灰/深蓝（难过）
  - 无记录 → 留白
- 整体呈现一个月的情绪色谱。

#### 2. 当月数据稀疏

- 缺记录的日子留白，不加标记。
- 底部轻提示"记录更多日子，日历会变得更完整"。

#### 3. 跨月查看

- 支持左右滑动切换月份。
- 未来月份不可见（或灰色不可点击）。
- 过去月份无限制回溯。

#### 4. 今日标记

- 当天日期有细圈环绕，不与情绪颜色冲突。

### 交互细节

- **点击某一天**：弹出轻量浮层，显示那天的表情和可选标签；如果通过今日总结关联，显示"那天你完成了散步和阅读"。
- **长按某个日期**可以快捷补记（漏记的日子），允许回到过去记录，但有"补记"标记区别于当天实时记录。

### 极端情况

| 场景 | 处理方式 |
| --- | --- |
| 一次性补记大量空白日期 | 不限制用户；趋势分析中标注"部分历史记录为补记" |
| 整月😭（极端月份） | 不修饰不隐藏，真实呈现情绪表达 |
| 用户从未记录过 | 展示空日历+引导"选一个表情开始记录吧" |

### 产品逻辑断裂点（待修复）

- [ ] 页面未创建
- [ ] 月历网格设计和颜色系统
- [ ] 点击日期浮层
- [ ] 长按补记功能
- [ ] 月度小统计

## Page 12：心情趋势

### 页面定位

用折线图展示30天内的情绪、压力、睡眠、幸福指数趋势变化。

### 核心信息架构

- 顶部：时间范围切换（7天/14天/30天）
- 维度切换tab：心情 / 压力 / 睡眠 / 幸福
- 折线图区域（温暖手绘感，不用冰冷数据图表风格）
- 高点/低点标注
- 底部AI轻量总结

### 状态清单

#### 1. 数据充足（≥14天记录）

- 平滑折线图，标注高点和低点。
- 支持切换维度（心情/压力/睡眠/幸福）。
- 多维度叠加展示（可选）：心情+睡眠叠加，观察相关性。

#### 2. 数据不足（<14天）

- 显示折线但用虚线表示数据不稳定。
- 提示"再记录一周，趋势会更有参考性"。

#### 3. 无数据

- 友好引导图，解释"记录心情后，这里会出现你的情绪地图"。
- 提供"选一个表情开始记录"入口。

### 交互细节

- X轴时间轴可缩放（7天/14天/30天）。
- 点击折线上某点，弹窗显示当天具体数据。
- 底部**非常克制**的总结语："你的情绪波动在正常范围内"，不做过度解读。

### 极端情况

| 场景 | 处理方式 |
| --- | --- |
| 用户感受"被数据分析"的不适 | 整体设计柔和，避免冰冷仪表盘风格，用温暖手绘感图表 |
| 数据出现异常值（连续极低） | 不做自动诊断，但在AI分析中提供轻量关注 |
| 数据量很大（使用超过一年） | 支持年度视图，简化为月均情绪色谱 |

### 产品逻辑断裂点（待修复）

- [ ] 当前简化版需升级为温暖手绘感图表
- [ ] 多维度切换（压力/睡眠/幸福需数据采集入口）
- [ ] 数据不足状态设计
- [ ] 高点低点标注
- [ ] 避免仪表盘冰冷感

## Page 13：AI 情绪分析

### 页面定位

基于长期情绪数据，生成个性化的情绪洞察和温和建议。**不是心理咨询，不做诊断。**

### 核心信息架构

- 分析周期选择（本月/近30天/上月）
- AI洞察卡片（主要发现）
- 情绪模式分析
- 温和建议
- 求助资源（常驻底部）

### 状态清单

#### 1. 数据积累足够（≥30天）

- 生成分析报告，包含：
  - 主要情绪状态
  - 波动周期
  - 与生活事件的关联趋势（心情好的日子是否完成了更多目标）
  - 睡眠与心情的关系
  - 一个温暖的建议

#### 2. 数据不足

- 不显示假的或空洞分析。
- 展示"我正在学习你的情绪节奏，再给我一些时间"，提示还需要多少天。

#### 3. 检测到持续低落期

- 分析报告中**必须**包含关怀性语言。
- 不能只说"你最近压力很大"。
- 应该是："这段时间可能不太容易，你已经很努力了。"
- 提供轻量自我照顾建议，不替代专业心理咨询。

### 交互细节

- 分析报告按月生成，展示"对比上月"的变化箭头。
- 用户可以对分析结果反馈（"说中了"/"不太对"），帮助AI校准。
- 提供导出/分享报告功能，方便用户与信任的人或咨询师分享。

### 极端情况（产品伦理底线）

| 场景 | 处理方式 |
| --- | --- |
| 数据指向可能的心理健康风险 | **预设安全协议**：绝对不给出诊断性语言；提供专业求助资源入口（24小时心理援助热线等）；这是产品伦理底线 |
| 用户长期未记录突然回来 | 报告不中断，标注"这段时间我们没有记录"，保持数据透明度 |
| 用户对AI分析感到不适 | 提供"关闭情绪分析"选项，仅保留基础记录功能 |

## 设计原则（全局）

1. **零摩擦记录**：点一下就完成，不加步骤，不加确认。
2. **不施压**：没有红点、没有催促、没有"今天还没记录"。
3. **温暖不诊断**：AI给的是生活建议，不是心理诊断。
4. **数据柔和呈现**：图表温暖手绘感，不做冰冷仪表盘。
5. **安全底线**：持续低落状态必须有专业资源入口，这是产品责任。
6. **自愿原则**：所有高级功能（标签/文字/分析）都是可选的，基础记录永远一键完成。
