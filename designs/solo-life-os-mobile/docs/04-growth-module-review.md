# Growth 模块产品评审文档

> 模块定位：每天成长一点。把长期目标拆解成每日可执行的小任务，用记录和数据给用户正反馈。
> 核心理念：只激励不惩罚，记录本身就是价值。
> 与 Today 的关系：Today 的"今日任务"（喝水/运动/阳光/早睡）是 Growth 的每日触点，Growth 是长期目标的管理中心。

## Page 14：成长目标（Growth 首页）

### 页面定位

展示用户设定的个人成长目标列表（英语、摄影、跑步、阅读等），每个目标有进度、详情入口。

### 核心信息架构

- 顶部：日期问候 + 今日完成概览
- **焦点目标区**：最多3个当前关注目标，大卡片展示
- 其他活跃目标：小卡片列表
- AI今日成长计划：自动生成的当日成长建议
- 连续打卡总天数
- 底部导航

### 状态清单

#### 1. 无目标

- 不能是空白页。
- 提供几个预设目标模板（"每月读一本书""每天散步30分钟""学英语10分钟""每周拍照3次"），附带好看的插图/图标。
- 一键创建，降低起步门槛。

#### 2. 多个活跃目标

- 卡片式展示，每个卡片包含：
  - 目标名称 + emoji/图标
  - 进度环/进度条
  - 一句话进展（"坚持了21天"）
  - 今日是否完成标记

#### 3. 目标已达成

- 卡片变为完成态（庆祝色/徽章）。
- 展示成就徽章。
- 提供"设为已完成"或"继续下一阶段"选择。

#### 4. 目标已停滞/放弃

- 超过30天无活动记录，卡片颜色变淡。
- **不自动删除**。
- 用户可以唤醒或归档。

### 交互细节

- 点击卡片进入详情，长按可编辑或暂停目标。
- **"当前关注"焦点目标**：一次最多3个，其他目标收起到下方。
- 创建新目标流程：选择类别 → 设定周期/频次 → 可选设置提醒 → 完成。最多3步。
- 每个目标卡片上有快捷打卡按钮（一键标记今日完成）。

### 极端情况

| 场景 | 处理方式 |
| --- | --- |
| 创建过多目标（>10个） | 温和提醒"现在有N个目标在进行，要不要聚焦最重要的3个？"防止目标稀释导致全部失败 |
| 周期性目标本周未完成 | 不惩罚；进度环显示"本周还剩2天"；过期自动进入下一周期，不累计愧疚 |
| 全部目标停滞 | 不显示"你所有目标都停滞了"这种负面文案；改为"最近很忙吧？随时可以回来" |
| 新用户第一天 | 预设3个轻量推荐（喝水/散步/阅读），可一键接受或自定义 |

### 产品逻辑断裂点（待修复）

- [ ] 当前原型缺少空态/预设目标模板
- [ ] 缺少焦点目标区（最多3个）
- [ ] 缺少快捷打卡按钮
- [ ] 缺少目标停滞状态（变淡但不删除）
- [ ] 创建新目标流程未设计
- [ ] 目标过多时的聚焦提醒

## Page 15：目标详情

### 页面定位

单个目标的详细视图，包含进度、统计、历史记录和下一步行动。

### 核心信息架构

- 顶部导航：返回 + 目标名称 + 更多操作（编辑/归档/删除）
- 目标头部：图标/封面 + 目标名称 + 大进度环 + 连续天数
- 今日打卡按钮（核心CTA）
- 本周完成日历/热力图
- 历史记录时间线
- 里程碑徽章
- AI建议/调整

### 状态清单

#### 1. 活跃目标

- 大进度环、连续打卡天数、本周完成情况、最近记录时间线。

#### 2. 新目标（刚开始 <7天）

- 小激励语："万事开头难，已经开始了 🌱"
- 突出快速打卡按钮。
- 不显示复杂统计。

#### 3. 长期坚持（>100天）

- 展示里程碑徽章（50天/100天/365天）。
- 回顾动画/庆祝。
- 这是情感奖励的关键时刻。

#### 4. 不同目标类型差异化展示

- **阅读**：书籍封面网格 + 已读页数 + 在读书籍
- **跑步**：里程统计 + 配速 + 路线地图缩略
- **摄影**：上传的照片缩略图网格
- **英语**：学习时长 + 连续天数 + 词汇量
- **冥想**：分钟数 + 连续天数

### 交互细节

- **打卡/记录完成**：核心操作，最显眼位置，一键完成。支持补记（标记"补记"）。
- 添加具体内容（书名/跑步路线/照片）：可选操作，不强制。
- "分享这个成就"：生成分享卡片。
- 调整目标（频次/时间）：不重置历史数据。

### 极端情况

| 场景 | 处理方式 |
| --- | --- |
| 连续中断后恢复 | 不从头计算连续天数；保留总累计天数；展示"当前连续"和"历史最长连续"，分别激励 |
| 删除目标 | 二次确认；提供"归档"作为温和替代（归档后数据和成就感不丢失） |
| 打卡内容缺失（如跑步忘开GPS） | 允许手动输入数据，不强制精确 |
| 目标周期结束（如"读完这本书"） | 自动标记完成 + 庆祝 + 推荐下一个相关目标 |

### 产品逻辑断裂点（待修复）

- [ ] 页面未创建

- [ ] 不同目标类型的差异化展示

- [ ] 归档vs删除的区分

## Page 16：成长统计

### 页面定位

多维度展示成长数据：时间投入分布、完成率曲线、效率时段分析。

### 核心信息架构

- 时间范围切换（周/月/年/全部）
- 完成率趋势（折线/柱状图）
- 各目标投入时间分布（饼图/环形图）
- 效率热力表（一周中哪些天/时段完成率最高）
- **心情关联洞察**（亮点）：心情好的日子是否目标完成率更高
- AI总结语

### 状态清单

#### 1. 数据充足

- 周/月/年完成率柱状图
- 各目标投入时间饼图
- 效率最高时段热力表
- 心情-完成率关联洞察

#### 2. 数据不足

- 仅展示已有数据简化版。
- 不强行填满图表（空的区域留白或显示"暂无数据"）。

#### 3. 与心情数据关联（亮点功能）

- 展示"心情好的日子，你完成目标的概率高出X%"
- 这是非常有价值的个人洞察，鼓励用户同时记录心情。

### 交互细节

- 时间范围切换（周/月/年/全部）。
- 每个图表区域有轻量AI总结："你最可能在周六上午完成最多的事。"
- 不做复杂筛选器，保持清爽。

### 极端情况

| 场景 | 处理方式 |
| --- | --- |
| 多目标交叉统计混乱 | 只展示全局维度+单个目标切换，不做复杂自定义交叉筛选 |
| 数据时间跨度大（多年） | 年度视图简化为月级聚合，不展示日级细节 |
| 完成率长期极低 | AI总结不批评，转向"你在哪些事情上花了最多时间"的中性描述 |

## Page 17：年度成长报告

### 页面定位

年度总结，AI撰写的个人成长叙事，面向回顾和分享。

### 与 Life Story 的区别

- **Growth 年度报告**：聚焦目标完成数据和能力成长（数字、成就、能力）。
- **Life Story**：更私密、情感化的人生叙事（回忆、情感、故事）。
- 两者互补，年度成长报告可引用 Life Story 中的事件丰富数据叙事。

### 核心信息架构

- 年度封面（年份+用户昵称）
- 年度总数据（总目标数/完成率/坚持最久目标）
- 今年新尝试
- 月度热力图
- 对比去年变化（第二年起）
- 最佳纪录（最长连续/单日最多完成）
- AI年度总结语
- 分享按钮

### 状态清单

#### 1. 年度中

- 展示从年初到现在累计数据预览。
- 不生成完整报告。
- 提示"年底会为你生成完整年度报告"。

#### 2. 年终/用户请求生成

- 完整年度报告：
  - 总目标数、完成率
  - 坚持最久的目标
  - 今年新尝试
  - 对比去年变化
  - AI总结语

#### 3. 第一年使用

- 没有对比数据。
- 强调"这是你开始记录的第一年"。
- 每一个记录都是新的，不与任何人比较。

### 交互细节

- 报告是可滚动长页面，用插画和数字混合叙事（类似Spotify Wrapped/Apple Music Replay）。
- 分享按钮在末尾，生成卡片式年度总结图。
- 可以保存到 Life Story 作为这一年成长的注脚。

### 极端情况

| 场景 | 处理方式 |
| --- | --- |
| 数据很少（只记录2个月） | 报告不夸大，诚实呈现；长度缩短但依然有意义 |
| 大部分目标未完成 | 不羞辱，不强调完成率；转向"你尝试了N件事""你记录了M次努力"，肯定记录本身的价值 |
| 全年零记录 | 不生成空洞报告；提示"这一年我们没有太多记录，但没关系，新的一年随时开始" |

## 设计原则（全局）

1. **只激励不惩罚**：进度环永远不显示红色警告，未完成只是"还没做"，不是"失败"。
2. **记录即价值**：哪怕没有完成目标，记录本身就值得肯定。
3. **聚焦原则**：最多3个焦点目标，防止目标过载。
4. **中断不可怕**：恢复打卡不从头计算，"当前连续"和"历史最长"并存。
5. **不累计愧疚**：周期性目标过期自动进入下一周期，不挂着"未完成"标签。
6. **差异化展示**：不同类型目标（阅读/跑步/摄影）展示不同的视觉语言。
7. **分享是自然延伸**：成就卡片和年度报告天然适合分享，不硬塞社交功能。
